# Robin — Portfolio (Robinhood Theme)

A Robinhood-app-themed version of Rohith Sadanala's portfolio — dark fintech design, signature green accents, a career-growth chart, skills presented as holdings, and projects as a watchlist.

- **Preview:** open `index.html` — a self-contained single-file build of the portfolio (open it in any browser, or serve it with any static host).
- **Main portfolio:** https://github.com/rohithsadanala/portfolio
- **Instagram-themed version:** https://github.com/rohithsadanala/insta

All content is resume-verified. Built with Muse.
